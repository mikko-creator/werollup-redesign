# Open decisions: werollup.com redesign

Written by the orchestrator on 2026-10-13 at 11:15, after WF1 (`docs/UNDERSTAND-REVIEW.md`). There are two kinds of entry:
- **A. Rulings applied by default.** The build follows them, and every one is reversible.
- **B. Questions for the operator or the client.** The build does not guess these. It carries the source as-is and flags it.

Evidence for each item is in the WF1 documents cited.
